# 纸艺定格科普 · 提示词写法

**交付：画风锁 +（可选）分镜表 + 单图/系列图/视频 H3 prompt。** 默认模型意图：MiniMax-H3。

## 全局锁（每条 prompt 重复）

- 手工纸艺定格、微缩剧场箱、多层卡纸**可见厚度**  
- 纤维/折痕/撕边、**层间真实投影**、微距景深  
- 纸偶分件；标签箭头也是纸片  
- 动作：小幅分段、短暂停顿、轻回弹、铰链/拉片/滑轨  
- **禁：** 丝滑 CG、塑料 3D、无纸边平面矢量、真人大动  

## 写前

主题 · 一句话学习目标 · 观众 · 时长(15/30/60) · 画幅(默认16:9) · 交付：单图 / 系列 / 5s 视频 / 分镜+视频  

只要单项：只写对应 prompt，不必硬走全包。

## 创意方向（3 选 1 写入风格句）

立体书旅程 / 纸科学家实验室 / 分层剖面 / 微缩自然剧场 / 纸片机关板  

## 分镜表（服务写镜）

| 时间 | 知识节拍 | 画面 | 纸艺运动 | 运镜/转场 | 音效意图 |
|---|---|---|---|---|---|

15s≈4 镜；30s≈5–6；60s≈7–9；**一镜一知识点**。  
运镜：缓推、横移视差、固定讲解、微距纹理。  
转场：翻页、立体展开、抽拉标签、纸云——禁电子故障霓虹（除非用户要）。

## Prompt 类型

**单图：** 主题词 + 全局锁 + 一层主知识 + 微距纸雕  

**系列图：** 共享材质光向身份；每张只进一步  

**5s 图生视频：** 保纸纹理分层；缓推/视差；机关轻动；禁融化高速环绕  

**分段视频（≤15s/段）：** 每秒级纸运动 + 继承角色布景光色锁 + 原生音频：纸触感 SFX + 轻教育感 BGM（可 N/A）

```text
[负向常挂] plastic CG, photoreal skin, flat vector no paper edge,
no layer shadow, liquid morph, cyber neon glitch, fast 360 orbit
```

字段化时接 `h3-prompt-writing`。

- [ ] 一镜一知识点  
- [ ] 运动像定格拨片  
- [ ] 记忆句/学习目标落在末镜
