# 音乐 MV 贴字 · 提示词写法

**交付：多分镜 Prompt 脚本**（可直接按镜投 H3）。拼接只写设计衔接句，不写工程步骤。

## 原则

- 文字是**空间设计层**，非底端字幕条（除非用户要普通字幕）  
- 用户音乐=主床；**>15s 拆 2–5s 多镜**  
- 有人声时 Typography 与表演词**逐字一致**；每镜一个主文字事件  
- 默认**硬切**跟鼓点；禁无意义淡入淡出  

## 写前锁定

画幅（9:16/16:9/1:1/21:9）· 目标时长 · 音乐窗口 · **锁定歌词**（用户词不改；无词则先锁原创短词）

## 三卡（写入 Global Lock）

| 卡 | 只写 | 勿写 |
|---|---|---|
| 文字卡 | 字体、质感、动效语言 | 人物场景 |
| 人物卡 | 脸气质服装姿态 | 复杂场景抢戏 |
| 场景卡 | 空间光影胶片感 | 大段可读字 |

## 分镜脚本模板

```text
[Global Aesthetic & Character Lock]
画幅 / 风格颗粒与色 / 三卡引用 / 禁淡入淡出、禁油亮AI脸 …

Shot 1 (0.0s-3.5s)
Vocal Line: "…"
Typography: "…"   # 空间位置：勿挡眼/主表情
Visual & Action: …
Camera & Motion: …
Transition Out: bass-hit hard cut / match pan …

Shot 2 …
```

每镜可再压成 `h3-prompt-writing` 字段；对白/歌词进 `<d>` 保留原文。

## 衔接句（写在脚本末）

1. 切点：句间停顿或强鼓点  
2. 同场景：尾帧→下镜首帧续写  
3. 跨景：同向运镜或 Match Cut  
4. 文字：切点砸出/砸入跟 Bass  
5. 全局同一颗粒/光向描述  

## 自检

- [ ] >15s 已拆镜  
- [ ] 词与贴字一致  
- [ ] 三卡不串味  
- [ ] 硬切与拍点意图写清
