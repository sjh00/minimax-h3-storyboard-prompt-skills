# H3 确认首图模板

## 核心规则

生成一张精致的 **16:9 横版**双人合作游戏主菜单确认图。画面由两套独立系统组成：

- **UI 框架（固定）**
- **视觉风格（动态）**

UI 框架规定布局、构图、信息层级、交互逻辑、阅读路径、菜单结构与可读性——这些不得改动。

`{visual_style}` 只控制艺术外观：渲染媒介、材质、色彩语言、光影情绪、环境风格、角色设计、服装语言、UI 材质、图标语言、字体外观、装饰母题与整体氛围。

换风格应像给同一套专业游戏菜单换美术方向，而不是重做界面。默认描述与 `{visual_style}` 冲突时，优先风格，同时保住 UI 框架。

---

## 设计目标

16:9 横版商业主机游戏主菜单样机：宣传图质感 + 专业 UI 清晰度。角色与界面自然融合，层级强、可读性高、构图干净，交互焦点明确。

---

## 整体风格

服从用户所选：`{visual_style}`。风格控制渲染媒介、插画风格、材质、色盘语言、环境、角色外观、服装、UI 外观、图标、字体处理、装饰与氛围。

全画面统一艺术语言，禁止混搭不兼容风格。UI 框架、布局、层级、构图、交互逻辑不随风格改变。

---

## 色彩

整套色盘从 `{visual_style}` 推导：

- `{main_background_color}`：主背景色
- `{ui_body_color}`：UI 主体色
- `{text_color}`：主文字色
- `{functional_accent_color}`：交互强调色
- 红色仅用于警示 / 危险 / 退出

主色控制在 5 种以内。按钮、玩家卡、图标、描边、高光、装饰、字体、特效共用同一色盘，禁止无关色乱入。

---

## 构图

固定 16:9 横版。中央放置 `{character_count}` 名可玩角色作为视觉主体；UI 环绕角色且不遮挡。

- 玩家信息卡：左上
- 主菜单：右侧纵向
- 底部装饰横条：按风格自然适配（丝带 / 警戒带 / 木板 / 石板 / 能量条 / 卷轴等）

Z 字阅读路径：玩家卡 → 角色 → 菜单 → Continue 按钮。Continue 始终是主视觉焦点。留白充足、可读性优先。

---

## 背景

背景从 `{visual_style}` 自然推导，服务界面而非抢戏。重要 UI 背后保留干净留白。纹理、环境细节、装饰母题仅在符合风格处使用。避免过度脏污、密集划痕、泼墨、干扰纹理。整体精致、现代、适合商业游戏菜单。

---

## 人物风格

所有角色严格服从 `{visual_style}`：渲染媒介、体型比例、面部风格化、服装语言、材质、受光、动画气质、整体品质。

仅身份锚点与姿态固定。五官渲染、眼睛、鼻型简化、嘴型、皮肤处理、表情风格、头身比例必须按风格重绘。默认角色风格不得压过用户选择。

---

## 角色 A / PLAYER 1

### 身份

角色参考图 1 仅作身份映射：可识别脸型轮廓、发型、眼镜（如有）、五官相对比例、个人特征。不继承真人摄影、皮肤纹理、现实光影、相机质感或原图风格。身份锚点不丢，脸必须重绘为 `{visual_style}`。禁止与其他角色互换身份。

### 外观

渲染、表情、服装、材质、配件全由风格推导，保持可玩角色剪影可辨。

### 动作

盘腿坐地；双手撑地；上身微微后仰；抬头望向镜头。

---

## 灯光

服从风格并保证可读：顶主光、补光、柔和环境反光、接触阴影、轻轮廓光、高质量 GI（适用时）。面部清晰可见；角色融入环境且与背景分离良好。

---

## 游戏 UI

专业商业主机主菜单。菜单结构、交互层级、间距、构图、阅读路径、信息架构固定；`{visual_style}` 只改艺术外观（材质、表面、描边、圆角、装饰、着色、光效、图标、字体、交互反馈）。

**不得改**：菜单层级、按钮顺序与位置、玩家卡位置、构图、交互逻辑、信息架构、可读性。界面应像一套完整设计系统，而非散件拼装。

---

## UI 视觉语言

完整 UI 外观由风格推导：按钮材质、描边语言、面板材质、装饰细节、边缘处理、视觉重量、高光、交互反馈、阴影、纹理。材质可为木/石/纸/皮/布/玻璃/水晶/全息/霓虹/金属/陶瓷/雕刻/彩绘/魔法能量/像素块/水彩纸/墨笔/漫画图形等任何自然属于风格者。全 UI 共享同一材质语言与艺术风格。

---

## 按钮排版规则

右侧纵向菜单；垂直节奏统一；同族设计；宽度适配文字；标题单行；禁止自动换行；禁止上下叠字；文字水平居中；内边距与按钮间距统一；避免杂乱。

---

## Continue 按钮

始终主视觉焦点。用风格内自然的强调方式：更大、更强对比、更亮、独特材质/描边/光/辉光/雕刻/魔法能量/全息/浮雕框/动效提示等。风格不支持时不强行霓虹/辉光。

---

## Start New Game / Settings / Exit Game

- **Start New Game**：位于 Continue 上方；次级按钮外观；可加一个风格合适的小图标；单行字。
- **Settings**：次级外观；一个由风格推导的设置图标；比例间距层级一致。
- **Exit Game**：次级外观；红色仅作危险点缀，不作主色；可加风格合适的退出图标。

---

## 玩家信息卡

左上 `{character_count}` 名玩家信息系统。外观服从风格；材质/描边/圆角/纹理/阴影/装饰/图标由风格推导。

每卡含：玩家标签、昵称、READY 状态。

```
PLAYER 1
{player1_name}
PLAYER 2
{player2_name}
```

READY 始终用功能强调色。高可读，并与整套界面视觉连贯。

---

## 图标系统

全界面统一图标族，由风格推导：线框/实心/几何/漫画/像素/阴刻/阳刻/彩绘/笔触/符文/全息/水晶/剪纸/折纸/浮雕/低多边形/扁平/风格化 3D 等。

共享：艺术风格、材质语言、透视、光处理、描边语言、色彩层级。简洁可辨、功能优先。每 UI 模块最多一排横向图标；禁止换行与上下堆叠；不抢戏。

---

## 字体

层级固定；外观服从风格（字族、装饰、纹理、材质、描边、光、阴影、磨损）。保持：高可读、强层级、菜单按钮单行、间距一致、高对比。按钮宽度适配文字长度；菜单标题永不换行。

---

## 游戏标题

显示 `{game_title}`，作为菜单主品牌元素。材质、装饰、字体、渲染服从风格。不模仿现有商业游戏 Logo；原创标题处理。高可读；禁止乱码符号与无意义字母。

---

## 交互状态

呈现为「正在使用中」的游戏菜单。按钮可显示风格内自然的交互反馈：hover、按下、魔法辉光、能量脉冲、全息高亮、雕刻发光、墨晕、笔触绽开、金属反射、纸浮雕、动边框、像素闪烁等。只用风格自然支持的效果。

---

## 渲染

商业级主菜单关键美术 + 主机菜单样机质感。角色、环境、UI、字体、图标、装饰像同一制作管线。优质渲染、强层级、专业商业呈现、高可读、构图平衡、干净收尾。

---

## 负面约束

禁止分屏、角色复制、身份互换、丢失身份锚点；禁止非写实风格下贴真实人像脸；禁止发型身份漂移；禁止不可读 UI、变形按钮、界面重叠；禁止随机文字/符号、水印；禁止抄袭游戏 Logo/品牌界面；禁止图标风格不一致、UI 材质混搭；禁止过度装饰、背景压过界面、布局崩溃、低可读。

---

## 媒介锁定

输出为精致商业游戏主视觉 + 专业主机主菜单样机。界面框架固定，仅艺术外观随 `{visual_style}` 变化。
